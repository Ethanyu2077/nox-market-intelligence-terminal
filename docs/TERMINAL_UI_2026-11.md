# 终端界面重构 · 2026-11 / Terminal shell redesign

目标：让 NOX 从「功能齐全的页面集合」变成**可长时间盯盘的专业终端**——信息密度高、层级稳定、
关键上下文常驻、键盘可达、缺失数据不伪装。

## 1. 重构前的问题（基于实际截图与代码审查）

| # | 问题 | 具体表现 |
| --- | --- | --- |
| 1 | 级联样式打架 | `styles.css` → `sidebar.css` → `refinement.css` 三层覆盖，字号从 8px 到 13px 混用，同一个 `.kpi` 有 4 套定义 |
| 2 | 顶栏失衡 | 项目选择器与交易所控件之间有大片空白；时间周期、交易所、连接状态挤在右侧；「只读 · 登录」横条占据每页首屏 |
| 3 | 缺少常驻行情上下文 | 价格 / OI / 资金费率只出现在部分页面的 KPI 卡片；换页即丢失当前标的与周期 |
| 4 | 观察列表不可用 | 只有当前项目加载行情，其余行显示 `—`（"Load on select"），无法作为价格板使用 |
| 5 | 导航语义混乱 | 13 个平铺入口；"Project research terminal" 与 "Market Overview" 重叠；`derivatives` 页面存在但无入口 |
| 6 | 无键盘路径 | 只有研究工作区内部有 ⌘K，全局无命令面板、无快捷键 |
| 7 | 状态语义不诚实 | 无 WebSocket 时顶栏显示 `DEGRADED`，即使 REST 数据只有 6 秒延迟 |
| 8 | 页面级布局事故 | 订单流页面在 1600px 下右侧栏内容互相覆盖、mini 图坐标轴溢出 |

## 2. 设计系统

- **Token 层**（`src/design/tokens.css`）：一套深色优先的语义色，把「交互强调色」与「涨跌色」分开
  （`--accent` vs `--up/--down`），避免绿色按钮被误读为上涨。
- **单一入口**（`src/index.css`）：旧页面样式先加载，设计系统最后加载并覆盖 shell 与基础组件；
  不再新增第四层 override。
- **字阶**：11 / 12 / 13 / 14 / 16 / 20 / 24，数字统一 tabular-nums；标题用 UI 字体，数据用等宽字体。
- **密度**：表格行 44px、表头 30px、KPI 条 78px，比原实现更紧凑但保留 12px 正文。

## 3. 结构变化

```
┌ Sidebar 212 ┐┌ Topbar 48 ─────────────────────────────┐
│ WATCHLIST   ││ 面包屑   ⌘K 搜索        Ask AI 状态 时钟 │
│ TERMINAL    ├──────────────────────────────────────────┤
│ FLOW&VENUES ││ MARKET BAR 52：标的 · 最新价 · 24H · OI │
│ INTELLIGENCE││ · Funding/倒计时 · Mark · 覆盖 · 周期   │
│ SYSTEM      ├──────────────────────────────────────────┤
│             ││ 页面内容                                 │
│             ├──────────────────────────────────────────┤
│ 连接状态     ││ Status bar 28：身份 · 标的 · 覆盖 · 时间 │
└─────────────┘└──────────────────────────────────────────┘
```

1. **市场条常驻**：任何项目页面都显示同一组行情与周期控件，换页不丢上下文。
2. **连接语义拆分**：`LIVE`（WebSocket）、`60S POLL`（仅 REST 轮询）、`STALE`、`DEGRADED`
   各有独立颜色与文案；不再把正常轮询标成降级。
3. **观察列表变成价格板**：新增 `GET /api/watchlist/quotes`，并发拉取每个项目的主数据源
   （12 秒 TTL、最多 12 个项目），返回价格 / 涨跌 / 成交 / OI / 资金费率 / Binance 24h 迷你走势 /
   覆盖状态。缺失仍为 `null`，不写 0。
4. **导航按任务分组**：观察 → 终端（含衍生品）→ 资金流与场所 → 情报 → 系统；恢复 Derivatives 入口。
5. **命令面板 ⌘K**：切换项目、跳转页面、执行操作；`⌘J` 随时唤起 DeepSeek 分析抽屉。
6. **账户状态进顶栏**：登录 / 角色 / 退出收进头像菜单，删除每页的只读横条。

## 4. AI 集成

详见 [DEEPSEEK_INTEGRATION.md](DEEPSEEK_INTEGRATION.md)。摘要：

- 研究面板改为 **DeepSeek / 证据报告** 双标签：模型回答与确定性报告并列，数值永远来自服务端。
- 聊天流式输出、来源编号 chip（悬停显示 venue/symbol/时间/质量）、`deepseek-reasoner` 推理折叠、
  结构化研判（观测 / 推断 / 假设+失效条件 / 风险 / 缺失数据）。
- 支持服务端密钥（需登录）与浏览器本地密钥（默认 sessionStorage，可选记住）。
- 模型列表运行时从上游 `/models` 发现，兼容 `deepseek-flash` / `deepseek-v4-pro` 与旧 `deepseek-chat`。

## 5. 修复清单

- 观察列表：所有项目实时报价 + 迷你走势 + 覆盖率标签 + 行内操作。
- 顶栏：移除空白断层，搜索、AI、连接、时钟、主题、语言、账户按频率排序。
- 表格：全局统一表头 30px / 行 44px，数字右对齐，首列在移动端吸附。
- 订单流：mini 图隐藏坐标轴文字，`.of-paired` 在窄面板下自动单列，右栏宽度与高度调整。
- 研究面板：不再继承 `.research-panel-body article` 的 padding/border，引用 chip 不再被撑成块级。
- 移动端：≤860px 侧栏抽屉化，观察列表头部纵向排列，状态栏隐藏，触控目标 ≥44px。
- 可访问性：`aria-current` / `role="tablist"` / `aria-selected` / 焦点环 / `prefers-reduced-motion`。
